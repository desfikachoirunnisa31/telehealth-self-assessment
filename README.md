## Cara menjalankan
1. Buka index.html di browser (atau jalankan: npx serve).
2. Buka menu Pengaturan, isi NIM, nama, kelas, dan token dari dosen.
3. Klik Simpan dan uji koneksi.

Token tidak disimpan di repository; hanya di localStorage browser pengguna.
